# Usage Guide

## Introduction

This guide explains how to use the UNIT3 repository.

## Step 1: Clone Repository

`git clone https://github.com/purahangowdaks/UNIT3.git`

## Step 2: Navigate to Project

`cd UNIT3`

## Step 3: Check Git Status

`git status`

## Step 4: Add Files

`git add .`

## Step 5: Commit Changes

`git commit -m "Updated project files"`

## Step 6: Push Changes

`git push origin main`
